# Kanban

A small task list that runs in the browser. Add a task and mark it done. The list is stored in `localStorage` and comes back after a refresh.

## Planned

- Drag cards between columns
- Multiple boards
- Accounts or a server with an AI agent

## Stack

- React 19
- TypeScript
- Vite
- Radix Themes

## Run

```bash
npm install
npm run dev
```
